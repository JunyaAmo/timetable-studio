# TIMETABLE STUDIO (試作版)

## 起動

Python があればターミナルで:

```bash
cd timetable-studio
python3 -m http.server 8000
```

`http://localhost:8000` をブラウザで開き、`F` キーを押すと全画面表示になります（ブラウザの権限制限によっては画面上の全画面ボタンを使ってください）。

※ ES Modules を使用するため、`index.html` を `file://` で直接開くのではなく、上記ローカルサーバーを利用してください。

## 編集箇所

- `js/config.js` : チーム名、ロゴのパス、配色、予定、空き時間圧縮設定
- `css/style.css` : 位置や文字の大きさ、余白
- `js/app.js` : 時刻による状態切り替え、横型タイムライン描画、背景の粒子アニメーション
- `assets/logo.svg` : 仮のチームロゴ（好きな画像に差し替え可能）

## 表示ルール

- 予定中: 予定名、残り分秒、進捗バー
- 予定がないとき: 時計を大きく表示、次の予定を補足表示
- 本日の予定が終了: 時計を大きく表示、終了メッセージ
- 下部: 予定と空白を並べる横型タイムライン（60分以上の空白は30分相当の表示幅）

## 現段階の制限

- `config.js` の予定は **毎日共通** のサンプル。曜日別・日付別の登録と編集画面、保存処理は後から実装します。
- 予定は同一日の中で終了し、互いに重複しない前提です。重複した予定はエラーにします。
- 背景アニメーションは Canvas による軽量試作です。p5.js に差し替え可能なよう独立させています。
- 実際の時計はモニターPCのローカル時刻を使います。
